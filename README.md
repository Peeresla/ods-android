# ОДС — Android

Нативное Android-приложение «Тренажёр МЧС» (Kotlin + Jetpack Compose). Повторяет веб-версию https://peeresla.github.io/ods/ по логике, текстам и поведению. Работает без интернета после первой загрузки. Подпись под иконкой — «ОДС».

Вопросы те же, что у веб-версии: приложение скачивает зашифрованный `questions.enc.json` с сайта. Вопросы, как и раньше, правятся в `Stajirovka/questions.json`, отдельно для Android ничего делать не нужно.

Все шаги ниже делаются на телефоне в браузере.

## 1. Ключ подписи (один раз)

Android ставит новую версию поверх старой, только если обе подписаны одним и тем же ключом. Ключ создаёт сам GitHub и сразу прячет в секреты репозитория — вы его не увидите, и вводить его никуда не нужно. Для этого GitHub-у нужен временный доступ к секретам.

**1. Создать ключ доступа к секретам**

Откройте https://github.com/settings/personal-access-tokens/new
- **Token name:** `ods-android-keys`
- **Expiration:** 7 дней (он нужен один раз).
- **Repository access:** *Only select repositories* → выберите `Peeresla/ods-android`.
- **Permissions → Repository permissions → Secrets:** *Read and write*.
- **Generate token** → скопируйте ключ.

**2. Сохранить его в секретах**

Откройте https://github.com/Peeresla/ods-android/settings/secrets/actions/new
- **Name:** `SECRETS_TOKEN`
- **Secret:** ключ из шага 1 → **Add secret**.

**3. Создать ключ подписи**

Откройте https://github.com/Peeresla/ods-android/actions/workflows/create-signing-key.yml → **Run workflow** → **Run workflow**. Через минуту появится зелёная галочка, и сразу начнётся сборка приложения (ещё 5–10 минут).

**4. Убрать временный доступ** (рекомендуется)

- https://github.com/settings/personal-access-tokens — удалите `ods-android-keys`.
- https://github.com/Peeresla/ods-android/settings/secrets/actions — удалите `SECRETS_TOKEN`. Секреты `ODS_KEYSTORE_…` и `ODS_KEY_…` **не трогайте**: без них новые версии не установятся поверх старой.

Повторный запуск шага 3 ничего не сломает: если ключ уже есть, он откажется создавать новый.

## 2. Установка

1. Откройте https://github.com/Peeresla/ods-android/releases/latest
2. В разделе **Assets** нажмите на файл `ods-1.0.N.apk` — он скачается.
3. Откройте скачанный файл (из уведомления или «Файлы» → «Загрузки»).
4. Телефон спросит, можно ли устанавливать приложения из браузера: **Настройки** → включите **«Разрешить из этого источника»** → вернитесь назад.
5. **Установить**. Если Play Защита предупредит о неизвестном приложении — **«Подробнее» → «Всё равно установить»**.
6. Откройте «ОДС» и введите тот же пароль, что в веб-версии. Пароль спрашивается один раз.

## 3. Обновление

Каждое изменение в этом репозитории само собирает новую версию. Скачайте свежий APK по той же ссылке https://github.com/Peeresla/ods-android/releases/latest и установите поверх — прогресс сохранится. Номер версии виден в приложении: «Настройки» → «О приложении».

Новые вопросы приходят без обновления приложения: достаточно открыть его при интернете.

## 4. Перенос прогресса из веб-версии (и обратно)

1. В веб-версии: **Настройки** → **Сохранить резервную копию** → сохраните файл (например, в Telegram «Избранное» или в «Файлы»).
2. Перенесите файл на Android-телефон.
3. В приложении: **Настройки** → **Восстановить** → выберите файл → **Восстановить**.

Обратно — так же: в приложении «Сохранить резервную копию» или «Поделиться копией», в веб-версии «Восстановить». Формат файла одинаковый.

## Если что-то не так

- **«Приложение не установлено»** при обновлении — APK подписан другим ключом. Такое бывает, только если секреты ключа удалили. Сохраните резервную копию прогресса, удалите приложение, установите новое, восстановите копию.
- **Сборка красная** — https://github.com/Peeresla/ods-android/actions, откройте красный запуск. GitHub также пришлёт письмо.
- **Нет APK в Releases**, а сборка зелёная — не создан ключ подписи (раздел 1).

## Для разработчика

```
core/   — вся логика на чистом Kotlin (повторяет app/app.js веб-версии) и юнит-тесты
app/    — Android: Compose-экраны, хранилище, загрузка и расшифровка банка
.github/workflows/build.yml              — тесты, сборка, публикация APK из main
.github/workflows/create-signing-key.yml — разовое создание ключа подписи
```

- Логику можно проверить без Android SDK: `./gradlew -PcoreOnly :core:test`.
- Контрольные отпечатки настоящего банка: `ODS_BANK_JSON=/путь/к/questions.json ./gradlew -PcoreOnly :core:test`. Сам банк сюда не кладётся — этот репозиторий публичный.
- Тестовый зашифрованный банк `core/src/test/resources/fixtures/test-bank.enc.json` сделан `tools/build.mjs` из `Stajirovka` с паролем `test-pass-123` (только для тестов). `web-backup.json` выгружен из настоящей веб-версии.
- Секреты сборки: `ODS_KEYSTORE_BASE64`, `ODS_KEYSTORE_PASSWORD`, `ODS_KEY_ALIAS`, `ODS_KEY_PASSWORD`. Ключи подписи (`*.jks`, `*.keystore`) в репозиторий не коммитить.
