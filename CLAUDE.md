# ОДС — Android: контекст для агента

Нативная Android-версия тренажёра МЧС (Kotlin + Jetpack Compose). Источник истины по логике и текстам — веб-версия в приватном репозитории `Peeresla/Stajirovka` (`app/app.js`, `app/styles.css`), ТЗ — `Stajirovka/docs/android-brief.md`.

Пользователь — не разработчик, работает только с телефона. Тексты, ответы и коммиты — на русском. Шаги для пользователя — пошагово для мобильного браузера, с прямыми ссылками на GitHub.

## Устройство

- `core/` — чистый Kotlin без Android: банк (`Bank.kt`), отпечатки (`Fingerprint.kt`), состояние и его JSON (`State.kt`), перенос прогресса (`Progress.kt`), серия дней (`Streak.kt`), тренировка, экзамен, резервная копия, расшифровка. Функции чистые, время передаётся параметром.
- `app/` — `AppViewModel` (всё состояние, действия как `ACTIONS` в app.js), `data/` (файл прогресса через AtomicFile, ключ банка под Android Keystore, загрузка банка), `ui/` (экраны и анимации).
- Переходы между экранами — свой маршрутизатор по «адресу», как хэш в веб-версии (`Route`), а не Navigation Compose: так «Назад» ведёт туда же, куда ссылка в шапке веб-версии, а направление анимации считается по глубине экрана.

## Правила

- Содержание — только из банка. Ничего не придумывать.
- Без аналитики и сторонних SDK. Сеть — только GET `https://peeresla.github.io/ods/questions.enc.json`.
- Репозиторий **публичный**: не класть сюда открытый `questions.json`, его шифрованную копию с настоящим паролем, пароли, ключи подписи.
- Формат резервной копии и шифрования — совместим с веб-версией. Изменения логики делать в обеих версиях.
- Решения из `Stajirovka/CLAUDE.md` («Принятые решения») действуют и здесь.

## Проверка

1. `./gradlew -PcoreOnly :core:test` — работает и без Android SDK.
2. Android-часть собирается в GitHub Actions (`build.yml`) на каждый push; в `main` с ключом подписи — публикация в Releases.
